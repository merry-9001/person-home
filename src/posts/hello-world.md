## 这个网站是怎么搭建的？

这个个人网站使用了以下技术栈：

- **Vue 3** — 渐进式 JavaScript 框架
- **Vite** — 下一代前端构建工具
- **TypeScript** — 类型安全的 JavaScript
- **Vue Router** — 官方路由管理器
- **Markdown-it** — Markdown 解析器

### 代码示例

```typescript
import { createApp } from 'vue'
import router from './router'
import App from './App.vue'

createApp(App).use(router).mount('#app')
```
